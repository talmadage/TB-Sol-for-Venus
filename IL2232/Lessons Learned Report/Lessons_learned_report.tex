\section{General summary of the project} 

This project focused on the implementation and verification of a parallel and a bit-serial version of a Risc-V. Both processor models need to be implemented on one FPGA and be tested by an advanced testbench that will be implemented on another FPGA. So the CPU and the testbench need to communicate with physical wire. This setup is intended to operate in the extreme environments of Venus, specifically under high-temperature. This work uses KTH's experimental Silicon-on-Insulator technology, which can operate at temperatures approaching Venus's 480°C requirement. However, this test station has a constraint, it has only 12 pads available. A serialisation and a communication protocol need to be set.

The project was carried out by dividing the work into two largely sub-projects: the testbench development with test set and implementation, and the communication system with especially the serialisation and protocol of the data transfer. This separation enabled parallel development and allowed team members to focus on different topics and architecture with at the end better efficiency. A significant portion of the work involved learning and adapting to unfamiliar tools, technologies, and design constraints. It strongly influenced both the schedule and the working methods.
